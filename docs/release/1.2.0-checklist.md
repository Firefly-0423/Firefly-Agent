## 由负责人发布 SDK

按现有 npm 可信发布工作流审查最终合入提交后执行。发布标签会触发工作流。

```bash
git tag plugin-sdk-v1.2.0
git push origin plugin-sdk-v1.2.0
```

工作流在 SDK 目录运行 `npm publish --access public`。先确认新版本可下载及安装，再由负责人决定弃用文案：

```bash
npm deprecate '@firefly_wu/plugin-sdk@<1.0.0' ""
```

## 回滚

发现阻断问题时暂停应用分发和 SDK 标签发布。已分发的应用保留问题日志及 1.2.0 数据备份，提供上一版安装包，1.1.x 继续使用其独立目录。已发布 SDK 应核对 dist-tag 后恢复到已验证版本，按需发布修正版本。保留原产物与追溯记录。
