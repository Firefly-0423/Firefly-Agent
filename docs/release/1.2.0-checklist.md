- [ ] 应用 package.json 与安装包版本断言均为 1.2.0，SDK package.json 也是 1.2.0。

## 由负责人执行打包和实机检查

```powershell
pnpm run package:win:dir
pnpm run package:win
```

从隔离启动参数 `--firefly-profile=smoke --firefly-isolation-root=<独立且已创建的绝对目录>` 启动。不要指向生产资料目录。保留检查日志和安装包信息。

- [ ] #117：会话 A 运行中切到 B，再切回 A；页面保留且 B 看不到详情。撤销授权后页面和待执行动作失效；验证多窗口中关闭最后一扇聊天窗口的清理。
- [ ] #118：上传无法完整读取的长附件，Chat 明确提示改用 Work。切换后用受支持的文档确认索引和问答。
- [ ] #121：在 Chat、Work、Code 运行中及待审批时刷新，在结束后重开。分别检查取消、超时和写盘失败。确认原回复原位回填、不会重复执行；重新生成、编辑后重发和压缩可以移除旧回复。
- [ ] #122：切换会话、隐藏或最小化时验证只读观察和交互限制，单纯失焦仍按既有焦点规则。切回后旧快照不能驱动点击或输入。
- [ ] 两个示例插件分别验证安装和启用、实际调用、取消、运行中崩溃后恢复、卸载，以及权限撤销和数据清理。
- [ ] 正式安装升级及卸载。确认 1.1.x 原数据目录保留，1.2.0 使用独立数据目录。

## 由负责人发布 SDK

按现有 npm 可信发布工作流审查最终合入提交后执行。发布标签会触发工作流。

```bash
git tag plugin-sdk-v1.2.0
git push origin plugin-sdk-v1.2.0
```

工作流在 SDK 目录运行 `npm publish --access public`。先确认新版本可下载及安装，再由负责人决定弃用文案：

```bash
npm deprecate '@firefly_wu/plugin-sdk@<1.0.0' ""
```

## 回滚

发现阻断问题时暂停应用分发和 SDK 标签发布。已分发的应用保留问题日志及 1.2.0 数据备份，提供上一版安装包，1.1.x 继续使用其独立目录。已发布 SDK 应核对 dist-tag 后恢复到已验证版本，按需发布修正版本。保留原产物与追溯记录。
