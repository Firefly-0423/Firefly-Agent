# Firefly 文档

按用途分目录。写作与施工流程见 [contributing/development-workflow.md](contributing/development-workflow.md)，环境、构建与测试说明见 [contributing/development.md](contributing/development.md)。

| 目录 | 放什么 |
| --- | --- |
| [design/](design/README.md) | 设计文档：一个功能解决什么问题、现在怎么实现、边界与未完成的部分 |
| [specs/](specs/) | 已经实现、有测试守着的对外行为规格 |
| [superpowers/plans/](superpowers/plans/) | 施工计划与进度文档（每个施工包一份计划、一份进度） |
| [superpowers/specs/](superpowers/specs/) | 施工前的功能规格 |
| [refactor/](refactor/) | 做过的重构记录：为什么做、前后结构、怎么验证、涉及的 PR |
| [internal-issue/](internal-issue/README.md) | 已知问题记录：现象、触发条件、根因、当前状态 |
| [references/](references/) | 查阅用的参考：支持的模型与协议、运行机制、各家模型服务的错误归类 |
| [plugins/](plugins/) | 插件开发文档 |
| [user-guide/](user-guide/index.md) | 用户指南 |
| [contributing/](contributing/) | 参与开发的流程与约定 |
| [qa/](qa/) | 验收清单与验收记录 |
| [reports/](reports/) | 评审与验证报告 |
| [security/](security/) | 安全与依赖风险登记 |

根目录下还有：

- [MAINTAINERS.md](MAINTAINERS.md)、[CONTRIBUTORS.md](CONTRIBUTORS.md)：维护者与贡献者；
- 免责声明：[中文](disclaimer.zh-CN.md)、[English](disclaimer.en.md)、[日本語](disclaimer.ja-JP.md)；
- 浏览器、插件发布与校验、外部技能兼容等专题说明（`browser-tools.md`、`plugin-*.md`、`external-skills-compatibility.md` 等），之后归入上面的分类。
