# 刷新后重新识别助手运行

状态：本地实现，待合并和实机验收

日期：2026-11-20。对应 [#113](https://github.com/Firefly-0423/Firefly-Agent/issues/113)。

Chat、Work、Code 的运行由主进程持有。页面刷新会丢失本页控制器，直接按未完成检查点恢复会把仍在执行的任务显示为中断；关闭原窗口后也可能错过最终答复。

验收按原助手消息验证三种情况：仍在运行时保留已有内容；运行结束但聊天消息还没存好时显示收尾；成功保存后按原消息 ID 回填。确认丢失的运行才走中断恢复。页面重新查看不应再次执行模型、工具、审批或队列任务。老记录不能靠“最近一次运行”猜配。临时会话不为此新增磁盘数据。

实机复核：分别在 Chat、Work、Code 中等待工具时刷新、结束后重开。再测等待审批、取消、超时、保存失败，以及两窗同看、原窗口已关闭。保存失败应保留可见正文和重试依据；显式删除会话后不应出现恢复的消息。实时增量接回由后续施工处理。
