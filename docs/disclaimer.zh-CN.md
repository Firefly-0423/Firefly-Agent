文件、命令、浏览器、插件、Skills、MCP 和伙伴委派可能读取资料、修改文件、访问网络或调用外部服务。持续授权与宽泛权限会扩大后续操作范围。请在授权前确认对象、范围及后果，按需关闭工具、撤销授权，备份重要工作区。

| 场景 | 行为与风险 |
|---|---|
| 桌面 Chat | AI 输出、角色表达、本地和外部数据处理风险适用。具体能力服从已启用工具和授权。 |
| 桌面 Work | 可涉及文件修改、任务执行、外部服务及伙伴委派。具体审批取决于权限和持续授权，部分操作可能直接执行。 |
| 桌面 Code | 可执行命令和修改代码。请核对工作区、命令及备份，执行可能造成不可逆变更。 |
| 渠道 Chat | 工具关闭时只聊天，QQ 与官方 QQ 机器人群聊强制采用此策略。 |
| 渠道 Work | 当前私聊开启工具后使用 Work 和 allow_all，工具直接执行，远程用户可能读写文件、执行命令。桌面审批预期不适用于此路径。 |
| 渠道 Code | 当前渠道策略只选择 Chat / Work。桌面切到 Code、绑定上下文均不授予渠道 Code 权限。 |

当前渠道 Work 边界以本修订日实现为准，后续收紧后会同步修订。仅向可信身份开放远程工具权限。

## ⑤ 数据存储与外部服务

设置、凭据、对话、记忆和日志可能保存在本机。当前正式目录由代码解析为 `%APPDATA%\Firefly`，1.2.0 计划采用 `%APPDATA%\Firefly-1.2.0`，切换仍待启动隔离施工落实。请在全新独立测试目录验收 1.2.0。不要将旧版数据复制到测试目录。开发启动默认使用仓库内隔离目录，详见用户指南。

本地存储仍需保护设备、备份及访问权限。根据配置，对话、附件、检索内容、工具结果和录音可能发送到模型、聊天平台、语音或其他服务，受相应服务的数据政策约束。渠道消息经相应平台处理。上下文绑定可共享文字上下文，记忆内容也可能参与模型请求，请避免提交未经授权的敏感资料。
