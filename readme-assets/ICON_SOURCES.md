# 徽章与图标来源

README 顶部是流萤头像，下面一行是徽章。

- **头像**：`assets/firefly.png`，与应用图标同一张图，由项目所有者绘制，见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。README 按 160 像素宽显示。
- **徽章**：打开页面时由浏览器从 [Shields.io](https://shields.io/) 获取，仓库不保存徽章文件。
  - 版本：`https://img.shields.io/github/v/release/Firefly-0423/Firefly-Agent`，由 Shields 读取本仓库在 GitHub 上的最新正式版本号，并链接到发布页。
  - GitHub、平台、在线试用与许可：[静态徽章](https://shields.io/badges/static-badge)，形式为 `https://img.shields.io/badge/<标签>-<内容>-<颜色>?style=flat`。GitHub 和 Windows 两枚带有 Shields 内置的品牌图标（`logo=github`、`logo=windows`）。
  - 徽章只说明仓库、版本、平台、网站与许可，不表示 CI 通过、质量认证或官方关联。
- **横幅**：`firefly-banner-*.gif` 等 Live2D 横幅素材仍保留在本目录，README 已不再使用。角色与模型许可见 [MODEL_LICENSE.md](../MODEL_LICENSE.md)。

页面离线或 Shields 不可用时，徽章不显示，其余内容不受影响。
