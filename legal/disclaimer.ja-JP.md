## ④ ツールおよび権限付与のリスク

ファイル、コマンド、ブラウザ、プラグイン、Skills、MCP およびパートナー委任（仲間への委任）は、資料の読み取り、ファイルの変更、ネットワークへのアクセスまたは外部サービスの呼び出しを行う場合があります。継続的な権限付与および広範な権限は、後続操作の影響範囲を拡大させます。権限を付与する前に対象、範囲および結果を確認し、必要に応じてツールを無効化、権限を取り消し、重要なワークスペースをバックアップしてください。

| シナリオ | 挙動とリスク |
|---|---|
| デスクトップ Chat | AI 出力、キャラクター表現、ローカルおよび外部データ処理に関するリスクが適用されます。具体的な機能は有効化されているツールおよび権限付与に従います。 |
| デスクトップ Work | ファイルの変更、タスクの実行、外部サービスおよびパートナー委任を伴う場合があります。具体的な承認は権限設定および継続的な権限付与に依存し、一部の操作は直接実行されることがあります。 |
| デスクトップ Code | コマンドの実行およびコードの変更が可能です。実行により不可逆な変更が生じる可能性があるため、事前にワークスペース、コマンドおよびバックアップをご確認ください。 |
| チャネル Chat | ツールが無効な場合は会話のみを行います。QQ および公式 QQ Bot グループチャットではこのポリシーが強制適用されます。 |
| チャネル Work | 現在の実装では、ダイレクトメッセージでツールを有効にすると Work と allow_all が使用され、ツールが直接実行されるため、リモートユーザーがファイルの読み書きやコマンド実行を行える可能性があります。デスクトップ版の承認期待はこの経路には適用されません。 |
| チャネル Code | 現在のチャネルポリシーでは Chat / Work のみが選択されます。デスクトップ側で Code に切り替えたりコンテキストをバインドしたりしても、チャネルに Code 権限は付与されません。 |

現在のチャネル Work の境界は本改訂日時点の実装に基づくものであり、今後の引き締めにあわせて改訂されます。信頼できる相手にのみリモートツール権限を開放してください。

## ⑤ データ保存および外部サービス

設定、認証情報、会話、記憶およびログはお使いの端末に保存される場合があります。現在、正式な保存先はコード上 `%APPDATA%\Firefly` として解決されており、1.2.0 では `%APPDATA%\Firefly-1.2.0` の採用を予定していますが、切り替えは起動分離の実装完了待ちです。1.2.0 の検証は新しく独立したテスト用ディレクトリで行い、旧バージョンのデータをテスト用ディレクトリへコピーしないでください。開発時の起動ではデフォルトでリポジトリ内の隔離ディレクトリを使用します。詳細はユーザーガイドをご参照ください。

ローカル保存であっても端末の保護、バックアップおよびアクセス権限の管理が必要です。設定内容に応じて、会話、添付ファイル、検索内容、ツール結果および音声録音はモデル、チャットプラットフォーム、音声またはその他のサービスへ送信される場合があり、各サービスのデータポリシーに従います。チャネルメッセージは該当プラットフォームを経由して処理されます。コンテキストのバインドによりテキストコンテキストが共有される場合があり、記憶内容もモデルへのリクエストに含まれる可能性があるため、無断で機密資料を送信しないようご注意ください。

## ⑥ AI 出力および操作リスク

AI は誤り、虚偽情報（ハルシネーション）、漏れ、または安全でない提案を生成する可能性があります。医療、法律、財務などの重要な判断については、有資格の専門家にご相談ください。削除、上書き、公開、決済などの不可逆な操作を実行する前には独自に検証を行い、復元およびバックアップ手段を保持してください。
