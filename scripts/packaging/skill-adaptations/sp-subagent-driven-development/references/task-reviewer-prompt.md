# Firefly task review brief
Firefly-maintained adaptation; see NOTICE and LICENSE.

Parent supplies requirement/plan excerpt, shared constraints, actual diff/range, implementation report and verification evidence.
Review in the existing general task context. Do not modify files, request a model, install packages or change permissions.

Compare actual code to requirements, not only the report. Check scope, contracts, security, history compatibility, cancellation, cleanup and tests. Distinguish missing evidence from missing implementation. Use exact path and line for each finding and explain impact. Do not re-run a whole suite when focused evidence is enough or contrary to user instructions.

Return pass/blocker findings, checks actually performed, and residual uncertainty. No findings does not establish untested services or GUI behavior.
